Sincronización de Chaturbate

Consulta el saldo semanal de cada cuenta y guarda una lectura diaria mientras la app esté abierta.

Sin configurar
El contador de Chaturbate se reinicia los lunes a las 00:00. La app consulta cada 5 minutos. Configura un proxy propio de Cloudflare Worker y las credenciales API de cada modelo. Los tokens API se guardan solo en este navegador y no se incluyen en respaldos. Si la app se cierra, las ganancias desde la última lectura se sumarán al próximo día que se sincronice.
Despliega worker/chaturbate-proxy.js. Si la app se cierra, las ganancias desde la última lectura se sumarán al próximo día sincronizado; si atraviesa el reinicio del lunes, ese saldo semanal perdido no se puede recuperar desde la API.

Sincronización de Stripchat

Consulta las ganancias semanales de las modelos de tu Studio y guarda lecturas diarias.

Sin configurar
La API de Studio requiere una clave creada por Stripchat y que cada modelo pertenezca a tu Studio. La clave se guarda en este navegador y se envía por HTTPS a tu Worker; no se incluye en los respaldos. La app consulta cada 5 minutos mientras está abierta.
Crea o consulta la API-Key en Stripchat Studio. El Worker también debe actualizarse para habilitar la ruta /stripchat/stats.
